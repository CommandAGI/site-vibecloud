    §01 · the description

    Capabilities, not product names.

    You name a web service, a database, a queue. The plan names the provider.

    §02 · how a plan moves

    Four states. One description.

    01 · described

    Describe

    A web app in Europe, a Postgres database, a queue, object storage. A ceiling for the month.

    02 · planned

    Plan

    Each resource goes to the cheapest healthy account that offers it there. The plan says why the others are out.

    03 · wired

    Provision and wire

    Each provider’s API is called once. Every resource is read back, then wired: URLs, endpoints, policies.

    04 · moved

    Fail over

    Google Cloud refuses. The database moves to AWS under the same description, and the record says what moved.
