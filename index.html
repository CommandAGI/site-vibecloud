Cloud control plane

vibeCloud turns one sentence into running infrastructure across AWS, Google Cloud and Cloudflare. It picks the cheapest healthy account for each service, wires them together, and moves a workload when a provider refuses, degrades or raises its price.

How it works

Four steps, one description. Nothing about a provider is in the description itself.

1. Describe

A web service, a database, a queue, object storage, a GPU, a region, a monthly ceiling. Capabilities, not product names.

2. Plan

Each resource goes to the cheapest healthy account that offers it in that region. The plan also says why the other accounts were left out, so you can check it.

3. Provision and wire

vibeCloud calls each provider's API, reads every resource back, then writes the wiring: database URL, queue endpoint, bucket policy and network rules.

4. Fail over

A provider that refuses, degrades or runs out of capacity is marked. The workload moves to another account under the same description, and the records say what moved.
