    §01 · la descripción

    Capacidades, no nombres de productos.

    Nombras un servicio web, una base de datos, una cola. El plan nombra el proveedor.

    §02 · cómo avanza un plan

    Cuatro estados. Una descripción.

    01 · described

    Describe

    Una aplicación web en Europa, una base de datos Postgres, una cola, almacenamiento de objetos. Un techo para el mes.

    02 · planned

    Planifica

    Cada recurso va a la cuenta sana más barata que lo ofrece allí. El plan dice por qué quedan fuera las demás.

    03 · wired

    Aprovisiona y conecta

    Se llama una vez a la API de cada proveedor. Cada recurso se vuelve a leer y se conecta: URL, extremos, políticas.

    04 · moved

    Migra

    Google Cloud se niega. La base de datos pasa a AWS con la misma descripción, y el registro dice qué se movió.
