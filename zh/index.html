    §01 · 描述

    写能力， 不写产品名。

    你写网页服务、数据库、队列。方案写出服务商。

    §02 · 方案如何推进

    四个状态，一份描述。

    01 · described

    描述

    欧洲的网页应用、Postgres 数据库、队列、对象存储，以及每月上限。

    02 · planned

    规划

    每个资源去往当地提供它的、最便宜的健康账户。方案写明其他账户为何落选。

    03 · wired

    开通并连接

    每个服务商的 API 只调用一次。每个资源都会被读回，然后连接：URL、端点、策略。

    04 · moved

    故障转移

    Google Cloud 拒绝服务。数据库在同一描述下迁到 AWS，记录写明迁移了什么。
